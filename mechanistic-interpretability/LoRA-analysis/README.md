# LoRA Analysis

For each model family, compare independently trained canonical, Mandarin-control and 14 linguistic-feature adapters at their midpoint and final checkpoints. Inspect the effective low-rank update `ΔW = (alpha/r) BA` by target projection and layer: update magnitude relative to pretrained weights, singular-subspace geometry and alignment with the registered control. Adapters are parallel adaptations from the same base, not successive fine-tunings.

Functional analysis evaluates on-input LoRA contributions using the same deterministic 160 welfare prompts (10 per category × tradeoff stratum) and 200 general prompts (10 per topical stratum) at both checkpoints. Aggregate global RMS as square root of total squared elements divided by total element count, with token masks applied consistently. Preserve separate results, sample manifests and sampling diagnostics for midpoint and final; compare layer/module effects and welfare-versus-general specificity. Weight-space alignment does not by itself demonstrate behavioral causation. See the [parent methodology](../README.md).
