# Mechanistic-Interpretability Datasets

The analysis uses three small supporting datasets alongside the existing fine-tuning corpora and the 800-scenario evaluation benchmark.

- `general_domain_prompts.json`: 1,000 varied, non-animal-welfare prompts for domain comparisons and activation-scale calibration.
- `welfare_concept_probes.json`: 1,000 matched positive/negative examples for linear probes of animal-welfare concept decodability. Each positive/negative pair shares a `pair_id`, and split assignment is pair-grouped.
- `steering_screening.jsonl`: 200 existing benchmark scenarios with welfare-supporting and welfare-opposing candidate continuations. Splits are `screen` (20), `validation` (80), and held-out `test` (100); the same fixed subsets apply to all models.

The first two files use **one JSON object per line despite their `.json` extension**; the loader accepts JSONL and JSON arrays. The steering file is required for log-probability screening and later held-out judged evaluation. It is not generated by the analysis scripts. Data validators enforce record counts, IDs, paired-label integrity, existing-scenario identity, category balance and split sizes.

Raw token activations are never written into this directory. Model checkpoints are external inputs rather than dataset artifacts.
